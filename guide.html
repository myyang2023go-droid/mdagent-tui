云端大脑 + 你电脑上的终端:对话、项目记忆、文件读写全程你批准。装好只花一分钟。

1一键安装

🐧 Linux / macOS —— 一条命令
curl -fsSL https://raw.githubusercontent.com/myyang2023go-droid/mdagent-tui/main/quick_tui.sh | sh

自动完成:下载 → 安装依赖(textual)→ 启动。需要 Python ≥ 3.8。

🪟 Windows —— 下载解压双击
① 打开仓库页 github.com/myyang2023go-droid/mdagent-tui → 绿色 Code 按钮 → Download ZIP
② 解压后双击 install-windows.bat(没装 Python 会提示你先装)
装好以后,日常启动就是一条命令:mdagent (Windows 新开终端同样输 mdagent)——不用再进目录跑脚本。

2首跑向导(共答三下)

提示输入说明
服务器直接回车连默认云端;自建服务器填自己的地址
选 1 / 21 或 21 = 账号密码登录(推荐) · 2 = 直接贴 mda_ 开头的 token
开放目录选个空文件夹云端智能体只能读写这个目录里的文件

3怎么拿到账号 / token

方式一:网页注册(自助,推荐)

浏览器打开 https://47.94.209.90/mdagent/register.html 填表提交(会弹证书警告,点「高级 → 继续访问」)。用户名和密码自己设, 大模型 key 填自己的;没有 key 可先填 8 位以上占位,批准后找管理员换。

或在 TUI 首跑向导里选 3 直接在终端注册。命令行提交(等效):

curl -sk https://47.94.209.90/mdagent/v1/apply \
  -H 'Content-Type: application/json' \
  -d '{"username":"你的用户名","password":"你设的密码",
       "provider":"kimi-coding","api_key":"sk-你的大模型key"}'

提交后状态为 pending,等管理员批准,然后就能在向导里选 1 用账号密码登录。

方式二:管理员直接发 token

管理员发给你一串 mda_… 开头的令牌 → 向导里选 2 贴进去即可 (贴错会当场报错,不会存)。之后在 TUI 里输 /login 用账号密码登录更方便, /apikey 可换成自己的大模型 key。

4安全须知(为什么放心用)

  • 目录囚禁:云端对你电脑的读写只限你选的开放目录,越界一律拒绝
  • 写操作逐笔批准:每次写/改/删文件弹批准卡,100 秒不答自动拒 (想免确认可输 /auto,自负其责)
  • 绝不野跑:智能体想直接跑 MD 引擎(lmp/gmx/mpirun…)会被硬拒;受管机器上必须走 supervise 编排门发车,全程留痕
  • 令牌安全:token 只存本机 ~/.mdagent_client.json(权限 600); 连接做证书指纹校验,防中间人冒充

5本地策略 mdagent.md(同 Claude Code 的 CLAUDE.md)

在开放目录放一个 mdagent.md,写你的规矩/偏好/项目背景:

# 我的策略
- 回复用中文,先给结论再给细节
- LAMMPS 输入统一用 metal 单位制
- 每次跑完模拟自动出温度/能量曲线

之后每轮对话自动附带(云端标记为策略注入,不进对话历史、不算轮次); /policy 随时查看,改完文件即生效。计算/仿真类任务,智能体会按内置纪律 先在开放目录建分类任务文件夹,并在其中维护任务级 mdagent.md(目标/参数/进度),续做时先读它。

6续做旧项目(--resume)

mdagent --resume          # 列出项目(按最近活跃),输序号续做
mdagent -c               # 直接续做最近的项目
mdagent --project 名字    # 直接指定项目

进去之后也可随时 /resume(列表选号)或 /project 名字 切换, 切了自动回放云端历史。

7常用命令

命令 / 按键作用
ESC打断当前任务(Claude Code 同款;云端温和收尾,已完成步骤不丢)
/login账号密码登录(token 自动取回、密码不回显;换号/重登都用它)
/resume挑旧项目续做(按最近活跃排序,输序号即切)
/project 名字切会话项目(上下文独立,自动回放云端历史)
/policy查看/重载本地策略 mdagent.md
/root 目录换开放给智能体的本地目录
/auto写操作免确认开关(默认关)
/goal目标面板:多步任务进度
/apikey换大模型 API Key
/status连接状态 + 每小时用量
/help全部命令(输入 / 自动弹菜单)
